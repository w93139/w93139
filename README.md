## 关于我 / A little about me

- **喜欢故事，也喜欢把它做出来。** 从人物、情节到人与 AI 的互动，既关心表达，也愿意动手验证想法。
- **习惯从真实场景出发。** 先看人们怎么用、哪里不顺，再决定该做什么。
- **爱拆解，也爱复用。** 把复杂问题拆成清楚的步骤，把有用的方法做成下一次还能用的工具。
- **对新东西保持好奇，对结果保持认真。** 尝试新模型和新工作流，也回看证据、反馈与实际效果。
